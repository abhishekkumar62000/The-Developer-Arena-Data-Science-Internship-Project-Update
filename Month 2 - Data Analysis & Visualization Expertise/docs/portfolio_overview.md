## Portfolio Structure Overview

1. **project1_sales_analysis** (Supermarket Data)
2. **project2_house_prices** (Real Estate Data)
3. **project3_weather_analysis** (Meteorological Data)
4. **project4_healthcare_covid** (Healthcare Trends Data)
5. **project5_finance_stock** (Financial Index Tracking Data)

Each folder contains distinct Python code in Jupyter Notebook form with their respective visual distributions, correlations, mean analysis, missing value calculations, and summary statistic reports generated automatically. 

**Insights Framework per project:**
- `Overview`: General total values, shapes, row counts, key date ranges.
- `Categorical Drill-Downs`: Value counts and sums for products, categories, features.
- `Financial Distributions`: Averages, Medians, Std Devs.
- `Time Series & Trends`: Best times, seasonality, spikes.
- `Business Recommendations`: Tangible action points based on findings.
