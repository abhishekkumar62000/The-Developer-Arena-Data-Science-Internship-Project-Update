# Month 2: Multi-Domain Data Analysis Portfolio

A professional portfolio consisting of 5 distinct data analysis projects covering different business domains. This project showcases data cleaning, statistical analysis, comprehensive visualizations, and actionable business insights using the Python data science stack (Pandas, Matplotlib, Seaborn).

## 🎯 Portfolio Objectives
- Advanced pandas operations and optimization.
- Data cleaning and preprocessing techniques.
- Comprehensive statistical analysis and insight generation.
- Interactive dashboards and clear reporting.

## 📁 Project Structure
```
Month 2 - Data Analysis & Visualization Expertise/
├── data/               # Source datasets (.csv, .xlsx)
├── notebooks/          # Jupyter notebooks (.ipynb)
├── reports/            # Exported summary reports (.md/.pdf format)
├── src/                # Reusable analysis and plotting logic (.py)
├── visualizations/     # Exported graphs and charts (.png/.jpg)
├── presentation/       # Key presentation slides or decks
├── docs/               # Portfolio overview & guidelines
├── requirements.txt    # Python dependencies
└── README.md           # This file
```

## 📊 The 5 Portfolio Projects
1. **Retail Domain**: Supermarket Sales Analysis (Dataset: `supermarket_sales.csv`).
2. **Real Estate Domain**: House Prices Analysis (Dataset: `house_prices.csv`).
3. **Weather Domain**: Meteorological Data Study (Simulated/Sample).
4. **Healthcare Domain**: COVID/Health Trends (Simulated/Sample).
5. **Finance Domain**: Stock Market Risk Assessment (Simulated/Sample).

## 🛠️ Setup Instructions
1. Install dependencies via `pip install -r requirements.txt`.
2. Ensure you have Jupyter Notebook or Jupyter Lab installed (`pip install jupyterlab`).
3. Launch Jupyter from the root folder: `jupyter notebook`.
4. Open the files in the `notebooks/` directory and execute them cell by cell.
5. All generated charts will be automatically saved directly into the `visualizations/` folder.
